# Top Laptops 2026

Ky është një website statik në HTML/CSS/JavaScript.

## Publikim me GitHub Pages
1. Krijo një repository të ri në GitHub.
2. Ngarko `index.html`, `style.css` dhe `script.js`.
3. Shko te Settings → Pages.
4. Te Build and deployment zgjidh branch `main`.
5. Hape adresën që GitHub Pages të jep.

## Publikim me Cloudflare Pages
1. Krijo repository në GitHub dhe ngarko skedarët.
2. Në Cloudflare hap Workers & Pages → Create application → Pages.
3. Zgjidh Import an existing Git repository.
4. Zgjidh repository-n.
5. Për një website statik mund të përdorësh build command `exit 0`.
6. Publiko projektin dhe merr adresën `.pages.dev`.

Përpara se ta publikosh si website komercial, përditëso specifikat/çmimet dhe shto burimet e tua.
